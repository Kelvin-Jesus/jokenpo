# Jokenpô

Pedra, papel e tesoura contra o computador, feito com HTML, CSS e JavaScript puros.

**Jogue:** https://kelvin-jesus.github.io/jokenpo/

## Como funciona

- Você joga contra a CPU, que escolhe sua jogada aleatoriamente.
- Quem fizer 3 pontos primeiro vence (`PONTOS_PARA_VENCER` em `script.js`).
- Empates não pontuam.

## Rodar localmente

Abra o `index.html` no navegador. Não há dependências nem build.
